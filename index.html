What the model assumes

Key limitation

An idempotency key protects writes only if the destination enforces it atomically. Sending a header alone is not enough. Real HTTP 503 responses do not prove that a write never happened.

Negative lookup ≠ no write

Delayed indexing or concurrent workers can make “not found” an unsafe retry decision.
