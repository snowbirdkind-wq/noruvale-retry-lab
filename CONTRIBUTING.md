# Feedback & contributions

This project is a synthetic educational demo. Please discuss the **model assumptions** and missed edge cases, not private production workflows.

To report an issue, please include:

1. Scenario / strategy in the demo
2. Expected result and observed result
3. A fake, minimal reproduction with no secrets
4. Any relevant documented n8n/HTTP behavior (with a public link)

Do not submit passwords, access tokens, customer emails, billing information, or private logs.

Pull requests are welcome for educational accuracy and accessibility improvements, subject to review.
